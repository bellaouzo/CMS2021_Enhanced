## CMS21 Together (Modified) 1.0.1

### Changes
- Update checker now uses this repo (`bellaouzo/CMS2021_Enhanced`) instead of the upstream project
- Fixed version parsing for `1.0` / `1.0.1` style versions (no more false "update available" notices)
- Update popup includes a **View Release** button that opens the latest GitHub release page

### Install

1. Install [MelonLoader 0.5.7](https://melonwiki.xyz/) into Car Mechanic Simulator 2021
2. Extract the RAR into your game folder (merge `UserLibs` and `Mods`)
3. Launch the game

See `README.txt` inside the archive for full instructions.
