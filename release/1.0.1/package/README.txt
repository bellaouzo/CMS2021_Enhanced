CMS21 Together (Modified) v1.0.1
==================================

A modified multiplayer mod for Car Mechanic Simulator 2021.
Based on CMS21-Together by Fozkais and Meitzi.

REQUIREMENTS
------------
- Car Mechanic Simulator 2021 (Steam)
- MelonLoader version 0.5.7

INSTALLATION
------------
1. Close the game if it is running.

2. Install MelonLoader 0.5.7 into your game folder:
   https://melonwiki.xyz/
   Run the installer and select your Car Mechanic Simulator 2021 install.

3. Extract this archive into your game directory so the folders merge:
   ...\Car Mechanic Simulator 2021\
     UserLibs\
     Mods\

   You should end up with:
   ...\Car Mechanic Simulator 2021\UserLibs\Facepunch.Steamworks.Win64.dll
   ...\Car Mechanic Simulator 2021\UserLibs\steam_api64.dll
   ...\Car Mechanic Simulator 2021\Mods\CMS21-Together.dll

4. Launch the game. A new multiplayer button should appear in the menu.

GAME PASS / MICROSOFT STORE
---------------------------
If you are using the Game Pass version, delete Facepunch.Steamworks.Win64.dll
from the UserLibs folder after extracting. The mod will not work with that file
on Game Pass.

TROUBLESHOOTING
---------------
- All players in a lobby must use the same mod version.
- If MelonLoader fails to download Unity dependencies on first launch, see:
  https://github.com/Nahkato/MelonLoader-V0.5.7-fix.
- Back up your saves before playing multiplayer.
