## CMS21 Together (Modified) 1.0

First release of the enhanced fork with full co-op sync for garage tools, cars, stats, quests, outdoor work, customization, salon browsing, and player state.

### Install

1. Install [MelonLoader 0.5.7](https://melonwiki.xyz/) into Car Mechanic Simulator 2021
2. Extract the RAR into your game folder (merge `UserLibs` and `Mods`)
3. Launch the game — a multiplayer button should appear in the menu

See `README.txt` inside the archive for full instructions, Game Pass notes, and troubleshooting.

### Requirements

- All players must run mod version **1.0**
- MelonLoader **0.5.7** only
